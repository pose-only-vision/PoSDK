版本历史
========

**后续功能更新与用户文档以 GUI 版本为主。** v1.0.0 的相关说明保留用于历史版本查阅。

PoMVG 主要版本及其关键特性：

- **v2.1.1（当前 GUI 版）**：更新平台安装与程序关联说明，补充 Codex + PoSDK CLI 联合操作和 GUI Agent 使用指引。

- **v2.0.0（GUI 版）**：平台更名为 **PoMVG**。提供图形化工作环境，集成工作流搭建、算法运行、结果查看与插件开发。

  - **可视化工作流**：从工作流库选择预设，关联本地数据，配置模块与连接后运行；支持 ETH3D、Strecha 和 1DSfM 数据处理。
  - **评估与性能分析**：查看已记录的精度指标、模块耗时、CPU 和内存统计，查看运行日志并导出报告。
  - **三维可视化**：查看点云与相机位姿，支持分屏对比、视角联动、相机轨迹设置和视频导出。
  - **开发与扩展**：通过 IDE 创建、编译和测试 Method／Data 插件；可选用 Agent 辅助检查工作流与开发插件。同一份工作流也可通过 CLI 运行。

  macOS 用户可通过 DMG 安装。参见 :doc:`GUI 安装说明 <../installation/gui_installation>` 和 :doc:`快速开始 <../installation/cli_gui_guide>`。

- **v1.0.0.0（历史 Demo）**：仅限于 Strecha 数据集测试。安装与编译说明保留为历史参考；新用户请使用 GUI 版。
