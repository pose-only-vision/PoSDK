## 各平台需要关联哪些程序

| 工作流节点 | 支持的版本 | 需要关联的程序 |
| --- | --- | --- |
| **COLMAP Pipeline** | COLMAP 3.13.0.dev0 | **COLMAP**，选择 `bin/colmap`。此节点使用 COLMAP 自身读取图像，不需要 OpenMVG。 |
| **OpenMVG Pipeline** | OpenMVG 2.1.0，含 PoSDK 所需扩展 | **OpenMVG**，选择 `bin/openMVG_main_SfMInit_ImageListing`；其他 OpenMVG 配套程序须保留在同一 `bin` 目录。 |
| **GLOMAP Pipeline** | GLOMAP 1.1.0，含 PoSDK 所需扩展 | **GLOMAP + COLMAP + OpenMVG**，分别选择 `bin/glomap`、`bin/colmap` 和 `bin/openMVG_main_SfMInit_ImageListing`。COLMAP 用于特征提取与匹配，OpenMVG 用于图像列表等辅助处理。 |

以上为当前插件支持的版本。面板会检查程序能否启动、版本和所需功能是否兼容；系统中装有同名程序，也需要通过检测后才能关联。通过面板安装会自动采用对应的固定版本与必要扩展。

## 1. 打开面板并关联本地程序

1. 在工作流中**双击对应的平台节点**，打开“安装、关联与测试”面板。
2. 在 **关联本地程序** 区域点击 **重新扫描**，等待候选程序完成检测。
3. 如果没有找到已安装的程序，点击 **选择搜索目录…**，选择程序的安装目录或 Plugin SDK 目录，重新检测。也可点击 **手动选择…**，直接选择上表中的可执行文件。
4. 勾选标记为 **检测通过** 的候选，再点击 **关联所选程序**。看到该程序显示 **已关联** 后，关联才完成。
5. 如果是 GLOMAP 节点，对 GLOMAP、COLMAP、OpenMVG 三项分别完成关联。

扫描和勾选候选不会自动修改配置；点击关联按钮后，程序路径才会写入**当前节点**的配置。其他节点仍需各自检查关联状态。迁移到另一台电脑后，请重新关联当地安装的程序。

## 2. 没有可用程序时，从面板安装

当前自动安装支持 **Apple Silicon macOS**，需要网络连接和 **Xcode Command Line Tools**。尚未安装命令行工具时，在 macOS“终端”输入以下命令，并完成系统提示的安装：

```bash
xcode-select --install
```

:::{note}
面板中的 Download / Install 会尝试下载固定版本源码并在本机编译安装，但受网络、依赖库和编译工具链影响，**不能保证 100% 成功**。如果失败，可自行下载本页支持版本的源码（含必要的 PoSDK 扩展）并编译安装，再按第 1 节重新扫描、检测并关联 `bin` 中的可执行程序。
:::

回到平台节点的面板，按以下步骤操作：

1. 在 **下载并安装（可选）** 区域点击 **下载源码并安装**。
2. 等待下载、编译、安装和程序检查完成；下方的进度及 **运行记录** 会显示当前步骤。
3. 回到 **关联本地程序**，点击 **重新扫描**，选择新安装且检测通过的程序，点击 **关联所选程序**。安装完成后仍需执行这一步。
4. 运行下一节的小样例，确认程序实际可用。

COLMAP 节点只安装 COLMAP；OpenMVG 节点只安装 OpenMVG；GLOMAP 节点会安装它所需的 GLOMAP、COLMAP 和 OpenMVG。安装使用独立的本地目录，不需要手动替换系统中的依赖库。

如已下载完整源码但编译中断，可点击 **继续安装已下载源码**。如自动下载失败，展开 **手动下载：链接与 git 命令**，按面板给出的固定版本和目标目录完成下载，再点击 **下载源码并安装**。需要手动执行或保留安装材料时，可使用 **导出 install.sh 与小样例**。

## 3. 运行内置小样例

1. 确认本节点所需的每项程序都显示 **已关联**。
2. 在 **运行内置小样例** 区域点击 **运行小样例**。
3. 等待运行结束，检查 **运行记录** 中的恢复视图和三维点统计。
4. 点击 **打开测试结果**，查看本次测试的输出文件。

小样例包含 **9 张合成图像，约 1 MB**，用于检查安装与关联是否正常。结果保存在单独的测试目录；它不会替换工作流中的数据集，也不用于本页的正式精度评测。

## 4. 使用自己的图像和工作流

各平台的安装面板只负责程序安装、关联和样例测试。处理实际数据时，仍需在工作流中配置输入并运行：

1. 在数据读取节点关联数据集并选择场景，将**图像和相机内参**接入对应的平台节点。比较多个平台时，保持图像集合和内参一致。数据关联步骤可参考 [快速开始](../installation/cli_gui_guide.md)。
2. 为各平台指定单独的**工作目录**（`work_dir`），与原始图像和数据集目录分开；启用清空工作目录时，运行会清理该目录。
3. 按需设置重建方式。OpenMVG 的完整重建需要启用 **SfM 重建**（`enable_sfm_reconstruction=true`），并通过 `sfm_engine` 选择 `INCREMENTAL`、`INCREMENTALV2`、`GLOBAL` 或 `STELLAR`；关闭该开关时只运行预处理。
4. 保存工程并运行工作流，在节点日志中检查完成状态和输出目录。各平台生成的原生模型保存在各自工作目录中；需要由 GUI 统一保存的结果，再连接相应的 **输出控制** 节点。
5. 查看点云以及 **评估（Evaluator）**、**性能（Profiler）** 记录。计算真值位姿误差需要接入对应的参考数据；只有图像时，可以检查重建结构和恢复数量。

已有对比的输入条件、精度、恢复数量、耗时和重建文件见 [评测结果](results.rst)。

## 常见问题

| 面板提示或现象 | 处理方法 |
| --- | --- |
| 未找到本地程序 | 使用 **选择搜索目录…** 指向安装目录，或 **手动选择…** 指向实际可执行文件；仍无可用程序时，从第 2 步安装。 |
| 程序无法启动、缺少依赖库或依赖库不兼容 | 点击候选项的 **查看检测详情**，查看具体库名或错误。改选检测通过的程序，或通过面板安装支持的版本。仅有可执行文件、缺少配套库的安装无法使用。 |
| 版本不兼容或缺少所需功能 | 使用面板提供的固定版本安装；GLOMAP、OpenMVG 还需要相应的 PoSDK 扩展，同版本号本身不能保证兼容。 |
| 小样例提示先关联所有程序 | 回到第 1 步，确认当前节点的所有必需项都显示 **已关联**，尤其检查 GLOMAP 节点的三个程序。 |
| 已关联，但实际工作流没有重建结果 | 检查数据输入、工作目录及节点日志；OpenMVG 还需确认已启用 **SfM 重建**。样例通过只说明程序可运行，不代表实际数据已配置完成。 |
