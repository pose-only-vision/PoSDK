# v2.1.1 安装说明（GUI 版）

v2.1.1 提供 PoMVG 图形界面。macOS 用户下载 **DMG 安装包**，安装后即可打开使用，无需先编译源码或安装编译依赖。**后续功能更新与用户文档以 GUI 版本为主。**

## 1. 下载 DMG

打开 [PoMVG v2.1.1 官方发布页](https://github.com/pose-only-vision/PoSDK/releases/tag/v2.1.1)，在 **Assets** 中下载后缀为 **`.dmg`** 的安装包。选择适合自己 Mac 的版本，以发布页说明为准。

**Source code (zip / tar.gz) 是源码，不是 GUI 安装包。**

## 2. 安装并打开

1. 双击下载好的 `.dmg` 文件。
2. 将 **PoMVG 应用**拖入窗口里的 **Applications（应用程序）** 文件夹。
3. 等待复制完成，然后从“应用程序”打开 PoMVG。

安装完成后，可以推出 DMG 磁盘映像。以后直接从“应用程序”打开即可。

## 3. 跑通第一组数据

打开 [快速开始](cli_gui_guide.md)，跟着 ETH3D 示例操作：

**打开工作流 → 双击 DatasetLoader → 下载并解压数据 → 关联本地目录 → 选择场景 → 运行并查看点云。**

指南还介绍工作流创建、Agent、IDE 插件开发、3D 可视化和 CLI 的使用方式。

v1.0.0 的[源码安装说明](installation.md)保留为历史参考。
