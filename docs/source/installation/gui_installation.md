# v2.1.1 Installation Guide (GUI Version)

v2.1.1 provides the PoMVG graphical interface. On macOS, download the **DMG installer**, install the app and open it. No source build or compiler dependencies are required to run the GUI. **Future feature updates and user documentation will focus on the GUI edition.**

## 1. Download the DMG

Open the [official PoMVG v2.1.1 release page](https://github.com/pose-only-vision/PoSDK/releases/tag/v2.1.1) and download the **`.dmg`** file under **Assets**. Choose the version suitable for your Mac, following the release notes.

**Source code (zip / tar.gz) contains source files, not the GUI installer.**

## 2. Install and open

1. Double-click the downloaded `.dmg` file.
2. Drag the **PoMVG app** into the **Applications** folder shown in the window.
3. Wait for copying to finish, then open PoMVG from Applications.

You can eject the DMG after installation. Open PoMVG from Applications on subsequent launches.

## 3. Run your first dataset

Follow the ETH3D example in [Quick Start](cli_gui_guide.md):

**Open a workflow → double-click DatasetLoader → download and extract data → associate the local folder → select a scene → run and view the point cloud.**

The guide also covers workflow creation, Agent, IDE plugin development, 3D visualization and the CLI.

The v1.0.0 [source installation instructions](installation.md) are retained for historical reference.
