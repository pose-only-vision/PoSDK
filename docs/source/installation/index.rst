Installation Guide
==================

**Future feature updates and user documentation will focus on the GUI edition. New users should start with the v2.1.1 GUI.** The v1.0.0 installation instructions are retained for historical reference.

.. list-table::
   :header-rows: 1
   :widths: 24 44 32

   * - Version
     - Use
     - Installation
   * - **v2.1.1 (GUI)**
     - Run workflows, process datasets and view point clouds in the app
     - :doc:`Download and install the DMG <gui_installation>`
   * - **v1.0.0 (legacy source)**
     - Consult historical installation scripts and build requirements
     - :doc:`Historical source installation reference <installation>`

.. tip::

   To install v2.1.1: **download the DMG → drag the app into Applications → open PoMVG**.
   Then follow :doc:`Quick Start <cli_gui_guide>` to run your first ETH3D scene.
