Team Information
================

The PoMVG core engine and PoMVG library are developed and maintained by the VINF-SJTU team (`LinkedIn <https://www.linkedin.com/in/yuanxinwu/>`_).

- **Qi Cai**: Project lead, responsible for development and maintenance of the core engine (``po_core``) and GUI, and for plugin development.
- **Xinrui Li**: Development of the COLMAP/GLOMAP plugins and related data format conversion code for the PoMVG platform.

If you are interested in the project or have any questions, please contact us through the GitHub project page (or email).
