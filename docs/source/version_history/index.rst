Version History
===============

**Future feature updates and user documentation will focus on the GUI edition.** The v1.0.0 documentation is retained for historical reference.

PoMVG major versions and their key features:

- **v2.1.1 (current GUI edition)**: Updates platform installation and program association instructions, with guidance for using Codex with PoSDK CLI and the GUI Agent.

- **v2.0.0 (GUI Edition)**: The platform is renamed **PoMVG**. Provides a graphical workspace for building workflows, running algorithms, inspecting results, and developing plugins.

  - **Visual workflows**: Choose a preset from the workflow library, associate local data, configure modules and connections, and run ETH3D, Strecha, and 1DSfM processing workflows.
  - **Evaluation and profiling**: Inspect recorded accuracy metrics, module timings, CPU and memory statistics, view execution logs, and export reports.
  - **3D visualization**: View point clouds and camera poses, compare results in split views with linked viewpoints, configure camera trajectories, and export videos.
  - **Development and extensions**: Create, build, and test Method/Data plugins in the IDE. Optionally use Agent to help inspect workflows and develop plugins. The same saved workflow can also run through the CLI.

  macOS users can install the GUI from a DMG. See the :doc:`GUI Installation Guide <../installation/gui_installation>` and :doc:`Quick Start <../installation/cli_gui_guide>`.

- **v1.0.0.0 (historical demo)**: Limited to Strecha dataset testing. Installation and build instructions are retained for historical reference; new users should use the GUI edition.
