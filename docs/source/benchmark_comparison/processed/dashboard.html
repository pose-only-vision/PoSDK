Inputs and shared settings
  • Dataset coverage: 13 ETH3D, six Strecha and 15 1DSfM scenes.
  • ETH3D / Strecha inputs: dataset images and camera calibration; ETH3D uses the supplied undistorted DSLR images.
  • 1DSfM inputs: supplied features, candidate matches and camera calibration.
  • Environment: Apple M4 Max, 14 logical CPUs, 36 GiB RAM and macOS 26.5.2.
  • Run settings: platforms run independently with eight CPU threads per scene and fixed camera intrinsics. Shared settings, including thread count and camera intrinsics, remain consistent.
  • Evaluation: ETH3D / Strecha report angular rotation errors and similarity-aligned camera-center distances (meters); 1DSfM reports reprojection errors (pixels). Results use mean / median.

View recovery for all datasets and platforms: 100% neutral · 90%–<100% green · >50%–<90% yellow · ≤50% red.
